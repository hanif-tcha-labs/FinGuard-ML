# Mobile Money Fraud Detection

End-to-end fraud detection project on the [PaySim dataset](https://www.kaggle.com/datasets/ealaxi/paysim1),
a synthetic Mobile Money transaction dataset.

This is a work-in-progress project, built phase by phase:

Data Understanding → Data Quality → EDA → Leakage Analysis → Feature Engineering
→ Validation Strategy → Baseline Models → Model Comparison → Hyperparameter Tuning
→ Threshold Optimization → Explainability → ML Pipeline → Backend API → Frontend
→ Testing → Docker
